## Overview

iZotope Neutron combines an AI mix assistant, EQ, compressor, transient shaper, exciter, and gate in one plugin that intelligently analyzes your track and suggests starting settings.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iZotope Neutron** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Mix Assistant** | AI analyzes each track and balances levels intelligently |
| **Track Enhance** | Analyzes audio and suggests EQ and compression settings |
| **Transient Shaper** | Per-band transient attack and sustain control |
| **Unmask** | Sidechain-aware EQ prevents frequency masking between tracks |
